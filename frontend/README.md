# React + Vite
Project Description:
    A Library management system with frontend on react and tailwind
    and a backend built using express node and mongo db as the database.
    Backend running on port 5000 the api endpoint is 
        http://localhost:5000/api/books
    Frontend sends request using axios
    


Frontend React : 
    
    for running frontend npm run dev

Backend + Express :
    cd backend
    npm -y init
    installing dependendencies using npm install Cors DOTEnv Moongoose express 
    for running backend cd backend npm run dev
    runs on port 5000
    env file for backend containing following structure: 
        PORT= Port of your choice 5000 in my case
        MONGODB_URI= Your mongodb uri
